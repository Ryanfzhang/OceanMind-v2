## Reading the summary and two evidence tables

- Table 0 is the product-level acquisition/export summary. Required, unresolved and conditional routes are distinguished; it does not silently freeze missing specifications.

**Audit correction:** The previous version conflated whole-paper inputs with per-query requirements and treated method adaptations as reproductions. A shared topic, variable name or model family does not establish agreement. No unchanged task is certified as an exact numerical reproduction.

- Table 1 inventories original-paper groups D01–D11 and selected benchmark adaptations B01–B04. B-groups specify the revised tasks' acquisition/export needs, not additional copies of shared data. It also inventories the cited papers' relevant observations, simulation cases and analysis quantities. It is **not an instruction to download every group's contents for every linked task**. Original-paper periods remain explicit; storage is not the constraint.
- Table 2 separates **our dependency analysis of the current query** from the **paper evidence**. `ADAPTED` means related analysis but changed data/design; `REANCHOR` means the reference does not directly establish the requested analysis; `METHOD EXTENSION` means an additional test is ours; `IDEA` means background, not a published answer. `CORE MATCH` is a method match, not downloaded-data certification; `PARTIAL MATCH` means only part of the requested comparison has direct paper support.
- For a strict paper reproduction, use its selected figure/analysis, case, variables, region, dates and processing. For a benchmark adaptation, keep the declared input source and derive new evaluator references from it. Do not silently change “CMOMS 2011” to an idealized model day, “reanalysis” to Argo, or the query to fit available paper files. Such choices require a task revision.
- Model states, forcing, online tendencies and derived statistics are different things. MLD, SCM depth, heat content and eddy tracks are normally computed, not separate mandatory downloads. An online budget term is not guaranteed by a state variable with a similar name. Daily-mean velocity times daily-mean concentration need not reproduce the model's averaged tracer flux; remapping also need not preserve native-grid budget closure.
- Acquisition links are directories or request routes unless explicitly verified. Exact files, legacy versions and original model cases remain unfrozen. Generic NASA L3 links do not certify availability of a paper's 1-km imagery.
- All query inputs need units, coordinates/time, valid-data masks and provenance. Profiles need vertical coverage/QC; integrals need appropriate area/layer geometry. Named variables in Table 1 are scientific quantities, not guaranteed NetCDF names.
