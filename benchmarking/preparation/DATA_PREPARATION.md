# Data preparation — current accessible-data catalogue

Version **2026-09-08-accessible-v1** for the 15 non-CMOMS tasks. CMOMS/basic tasks are unchanged. The user authorized reducing tasks where original files or acquisition routes were unresolved. Do not describe these reduced analyses as exact reproductions of inaccessible observations.

Run the two commands in the [download guide](../download/README.md). Every non-CMOMS task now maps to implemented numerical-data acquisition groups; none requires private floats/gliders, author NEMO output, original ETOPO5, VGPM, CCMP, a separate ADT release or author chlorophyll reconstruction. Public availability is distinct from a successful local download. Provider outages or expired credentials still cause a failed status, not a false completion.

### Derived support, not extra downloads

Use native coordinate axes, depth and valid/fill masks. Compute regular-grid cell areas from coordinate edges; no external bathymetry is required for the revised non-CMOMS tasks. Missing ocean-colour values are not zero or necessarily land.

- Gulf analysis: 98–82 W, 18–30 N; east/west split at 90 W.
- Q17 central Gulf: 92–88 W, 23–27 N.
- Coastal box: 112–115 E, 21–23 N; offshore box: 115–118 E, 17–20 N.
- SEATS-area box: 115.5–116.5 E, 17.5–18.5 N.
- Vietnam box: 109–112 E, 10–16 N.
- ECS analysis: 120–128 E, 25–34 N; downloaded halo extends one degree on each side.

These boxes are benchmark choices, **not the original papers' polygons or bathymetric shelf masks**. They appear explicitly in each affected query. Gridded density/depth diagnostics remain limited by resolved wet columns; no extrapolation into unprovided layers. No presumed reanalysis event is forced to match the observed Poseidon.

## What is and is not complete

Numerical acquisition is now fully specified for all 15 non-CMOMS queries. The downloader writes `_download_all/coverage.json`; only `all_numerical_inputs_complete: true` means both phases finished the declared numerical inventory. Run its `verify` command to recheck stored hashes without network access.

No actual complete server archive has yet been validated here. All scoring checklists remain draft. Independently calculate numerical references on the downloaded files; original paper plots for Q13–Q22 are retained as **context only**, not scoring targets. Never reuse a prior query's reference hash after this revision.

Idea tasks keep their related-work reading selections; shared authorized full texts still need staging. This is a literature preparation step, not an additional scientific-data dependency. Do not require the readings' original private/author datasets. CMOMS authorization, files and experiment identity remain the user's separate preparation.
